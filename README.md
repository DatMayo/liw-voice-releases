# LiW Proximity – Mumble-Plugin

Das Voice-Plugin für **[Life In Wilderness](https://playliw.com)**, den RedM-Server, auf dem jeder Spieler ein Tier ist.
Gesprochen wird über die kostenlose [Mumble](https://www.mumble.info/downloads/)-App: Das Plugin regelt die Lautstärke
jedes Spielers nach Entfernung und Sprechreichweite im Spiel, spielt den Rudelruf und lässt Stimmen in Höhlen und unter
Wasser dumpf klingen.

Hier liegen nur die fertigen Versionen – unter **[Releases](https://github.com/DatMayo/liw-voice-releases/releases/latest)**
oder direkt über **[playliw.com/voice](https://playliw.com/voice)** (immer die neueste Datei).

## Installieren

1. Mumble (ab Version 1.4) installieren.
2. `liw_proximity-<Version>.mumble_plugin` herunterladen und doppelklicken – oder in Mumble:
   Einstellungen → Plugins → „Plugin installieren“.
3. In Mumble unter Einstellungen → Plugins „LiW Proximity“ aktivieren; unter Audioausgabe positionsabhängiges Audio
   einschalten.
4. Mumble mit unserem Mumble-Server verbinden (Adresse im Discord) und das Spiel starten.

Ob alles läuft, zeigt das Spiel im Charaktermenü (J) unter Einstellungen → Voice. Hilfe gibt es im Discord.

# LiW Proximity – Mumble plugin

The voice plugin for **[Life In Wilderness](https://playliw.com)**, the RedM server where every player is an animal.
Install it (Mumble 1.4 or newer: download `liw_proximity-<version>.mumble_plugin` from the
[releases](https://github.com/DatMayo/liw-voice-releases/releases/latest) or [playliw.com/voice](https://playliw.com/voice),
double-click it), enable “LiW Proximity” under Settings → Plugins and positional audio under Audio output, connect Mumble
to our server (address on the Discord) and start the game. The character menu (J) → Settings → Voice shows whether
everything works.
