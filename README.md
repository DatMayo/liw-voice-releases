## Deutsch

### Was ist das?

Auf Life In Wilderness – dem RedM-Server, auf dem jeder Spieler ein Tier ist – wird über die kostenlose
[Mumble](https://www.mumble.info/downloads/)-App gesprochen. Das Plugin regelt die Lautstärke jedes Spielers nach
Entfernung und Sprechreichweite im Spiel, spielt den Rudelruf und lässt Stimmen in Höhlen und unter Wasser dumpf
klingen. Der eingebaute Sprachchat von RedM ist aus: **Ohne das Plugin hörst du niemanden und niemand hört dich.**

Hier liegen nur die fertigen Versionen (Windows x64 und Linux x64).

### Installieren

1. Mumble (ab Version 1.4) installieren.
2. `liw_proximity-<Version>.mumble_plugin` über [playliw.com/voice](https://playliw.com/voice) herunterladen und
   doppelklicken – oder in Mumble: Einstellungen → Plugins → „Plugin installieren“.
3. In Mumble unter Einstellungen → Plugins „LiW Proximity“ aktivieren; unter Audioausgabe positionsabhängiges Audio
   einschalten.
4. Mumble mit unserem Server **`talk.playliw.com`** verbinden (Server → Verbinden → Server hinzufügen, Port 64738) und das Spiel starten. Das Plugin verbindet sich
   selbst und schiebt dich in den Spielkanal.

Neue Version: einfach die neue Datei genauso installieren, sie ersetzt die alte.

### Prüfen, ob es läuft

Im Spiel: Charaktermenü (<kbd>J</kbd>) → Einstellungen → **Voice** – ein Häkchen je Schritt. Push-to-Talk oder
Sprachaktivierung, Lautstärke und Mikrofon stellst du in Mumble ein.

### Töne des Plugins

| Ton | Bedeutung |
|---|---|
| zwei steigende Töne | mit dem Spiel verbunden |
| zwei fallende Töne | Verbindung zum Spiel weg |
| drei leise Töne | im Spielkanal |
| zwei tiefe Töne | Spielkanal fehlt oder Passwort falsch |
| kurzer Ruf | ein Rudelruf erreicht dich |

### Hilfe

Fragen und Probleme: im Discord von Life In Wilderness (Link auf [playliw.com](https://playliw.com)).

## English

### What is it?

On Life In Wilderness – the RedM server where every player is an animal – you talk through the free
[Mumble](https://www.mumble.info/downloads/) app. The plugin sets every player's volume by distance and voice range in
the game, plays the pack call and makes voices sound muffled in caves and under water. RedM's built-in voice chat is
off: **without the plugin you hear nobody and nobody hears you.**

Only the finished versions are kept here (Windows x64 and Linux x64).

### Installing

1. Install Mumble (version 1.4 or newer).
2. Download `liw_proximity-<version>.mumble_plugin` from [playliw.com/voice](https://playliw.com/voice) and
   double-click it – or in Mumble: Settings → Plugins → “Install plugin”.
3. In Mumble enable “LiW Proximity” under Settings → Plugins; switch on positional audio under Audio output.
4. Connect Mumble to our server **`talk.playliw.com`** (Server → Connect → Add New, port 64738) and start the game. The plugin links up by itself and
   moves you into the game channel.

New version: install the new file the same way, it replaces the old one.

### Checking that it works

In game: character menu (<kbd>J</kbd>) → Settings → **Voice** – one tick per step. Push-to-talk or voice activation,
volume and microphone are set in Mumble.

### Plugin tones

| Tone | Meaning |
|---|---|
| two rising notes | linked to the game |
| two falling notes | link to the game lost |
| three soft notes | in the game channel |
| two low notes | game channel missing or wrong password |
| a short call | a pack call reaches you |

Questions and problems: on the Life In Wilderness Discord (link on [playliw.com](https://playliw.com)).
